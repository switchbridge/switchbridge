# @switchbridge/dashboard

Веб-интерфейс панели управления Switchbridge на React, Vite и TypeScript.

## Назначение
- **Setup Wizard:** Пошаговый мастер первой настройки инстанса Switchbridge (выбор режима аутентификации, создание администратора или подключение OIDC/Keycloak).
- **Экран входа (Login Screen):** Локальная авторизация или вход через внешний Identity Provider (SSO).
- **Интернационализация (i18n):** Поддержка многоязычности (английский, русский и др.) в `src/i18n.ts`.
- **Дашборд мониторинга:** Просмотр активных мостов, каналов, лога сообщений и статистики.

## Сборка и запуск в dev-режиме
```bash
npm run dev
npm run build
```
